# 队伍文档提交要求（必读）

用于 CRTC2026 中期考核「文档评估」，请在 **2026年10月12日 24:00** 前完成个人部分。

## 一、格式要求（最重要）

1. 文档必须是 **Markdown 格式**，文件后缀为 **`.md`**
2. **不要发 Word、TXT、图片截图**（评分只认 Markdown）
3. 不会写 Markdown 的：
   - 用 VSCode：新建文件 → 文件名写 `xxx.md` → 直接写
   - 或用网页版在线 Markdown 编辑器（浏览器搜"在线 Markdown 编辑器"）

## 二、内容要求

按「单个功能 = 一个板块」来写，每个功能板块包含：

```
## 功能名（用 ## 做标题）

功能描述：这个功能是做什么的、预期效果

开发历程：按时间记录（做了什么 → 遇到什么问题 → 怎么解决）

为什么这样做（拿高分关键）：
- 技术选型对比：为什么用 A 不用 B
- 遇到的问题与解决方案
- 迭代优化过程
```

**评分重点提醒**：不是"做了什么"就完事，要写出**"为什么这样做"**——选型对比、踩坑记录、解决思路，这部分决定分数高低。

## 三、文件命名

统一格式：**`你的名字-功能名.md`**

示例：`张三-底盘驱动.md`、`李四-视觉识别.md`

**避免重名**（同名文件会互相覆盖，很麻烦）。

## 四、提交方式

写好后把 `.md` 文件**发到队伍群**（或直接发队长），由队长统一上传到仓库。

## 五、节奏建议

- 不要攒到最后一天交，每周至少更新一次
- 可以先交初稿，后续补充完善
- 参考模板：本文件夹下的 `示例-文档模板.md`
