# 文档目录

本文件夹存放队伍的学习日志与机器人设计文档，用于 CRTC2026 中期考核的「文档评估」板块。

## 写作规范（依据 CRTC2026 规则文档）

- 格式：Markdown（`.md`）
- 内容按机器人设计进度时间点**从早到晚**组织
- 以**单个机器人功能为一个板块**：功能名用 `##` 标题（H2），正文写功能描述与开发历程
- 拿高分关键：不只写"做了什么"，更要写**"为什么这样做"**（技术选型对比、遇到的难点、解决方案、迭代优化过程）
